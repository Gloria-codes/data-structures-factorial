 Stack as a Data Structure

A **stack** is a linear data structure in which insertion and deletion take place at the top.

A stack follows **LIFO (Last In, First Out)**. Therefore, the last item added is the first item removed.

Example:

Push 10
Push 20
Push 30

TOP -> 30
       20
       10


If an item is popped, 30 is removed first.

## Main Stack Operations

- **Push:** adds an item to the top.
- **Pop:** removes the item at the top.
- **Top:** views the item at the top.
- **Empty:** checks whether the stack is empty.

## Real-Life Applications

1. **Undo/Redo:** stores recent actions in applications.
2. **Browser history:** helps move back through recently visited pages.
3. **Function calls:** programming languages use a call stack to manage functions.
4. **Expression evaluation:** stacks help evaluate mathematical expressions.
5. **Backtracking:** useful for solving mazes and returning to previous choices.
6. **Depth-First Search:** stacks can be used to traverse graphs and trees.
