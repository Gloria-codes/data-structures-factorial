 Algorithms

## Input and Validation
1. Start.
2. Ask the user to enter n.
3. Check that n is greater than 0.
4. Check that n is not greater than 20.
5. If the value is invalid, display an error and stop.
6. Otherwise continue.

## Forward Stack Algorithm
1. Create an empty stack.
2. Push numbers from 1 to n.
3. Set factorial to 1.
4. Multiply factorial by each number from 1 to n.
5. Display each factorial.
6. Pop the stack values to demonstrate LIFO.
7. Stop.

## Backward Stack Algorithm
1. Create an empty stack.
2. Push numbers from n down to 1.
3. Set factorial to 1.
4. While the stack is not empty, read and remove the top value.
5. Multiply factorial by the removed value.
6. Display the factorial.
7. Stop.

## Overall
START -> Input n -> Validate -> Forward Stack -> Backward Stack -> END
